0. The following code uses a Linux server as an example.

1. Put the webpage content in the root directory of your website, and replace all addresses in the front-end code: ws://12.34.56.78:9999 with your own server's IP address + port number. The default port number of the server is 9999, which can be modified in websocketNode.js. After modification, use npx pm2 restart websocketNode.js to restart it. If you use HTTPS, you need to change the prefix ws to wss.

2. How to find the website root directory: It is recommended to use Nginx to manage your site.

3. Install Nginx
Use different package managers depending on your server's OS version (e.g., yum, apt, pacman, etc.).
Taking yum as an example: yum install nginx
Wait for the installation to complete, then use the following commands to control Nginx (administrators do not need the sudo prefix):
sudo systemctl start nginx    # Start Nginx
sudo systemctl stop nginx     # Stop Nginx
sudo systemctl restart nginx  # Restart Nginx

Now you can access the default Nginx page by entering your server's IP in the browser.

4. Find the Nginx default page folder and replace it with your own page files.
Generally, you can use the command which nginx to view the default page path of Nginx.
For example (/usr/share/nginx/html), copy and paste your html, css, and js files into it, then enter the IP address in the browser to access.

5. Note: After the function of intensity following the soft upper limit is turned on, the intensity upper limit will only be set to the channel intensity when the intensity upper limit changes. If the intensity upper limit of the channel in the intensity data sent upwards by the APP has not changed, do not set the intensity upper limit as the channel intensity. Because the device synchronises intensity data upwards every time the intensity is set, not making this judgement will cause an infinite loop.
